# Состояния и концентрация

Состояния находятся в карточке персонажа во вкладке «Здоровье». Концентрация — во вкладке «Спеллбуки». При активной концентрации над вкладками появляется кнопка быстрого перехода к ней. Состояния отображаются только во вкладке «Здоровье».

## Состояния

Нажми «Добавить состояние». В открывшемся окне найди состояние по названию и выбери его: описание появится до добавления. При необходимости раскрой «Заметка и особые правила», укажи источник или срок действия. Уже активные состояния помечены в списке. Для изменения заметки или особых правил нажми «Изменить» в карточке активного состояния. «Отмена» закрывает окно без сохранения. Описание раскрывается в карточке; полная запись справочника открывается отдельно. «Снять» удаляет только отметку с персонажа.

Состояния хранятся отдельно от эффектов заклинаний. Произвольные эффекты не попадают в список состояний. Сроки действия, преимущества, помехи и прочие последствия контролируются игроком: приложение не пытается выводить правила из произвольного текста справочника.

Галочка «Прерывает концентрацию» прекращает концентрацию и не позволяет начать новую, пока такое состояние активно. Отмечай её для состояний, которые по вашим правилам делают персонажа недееспособным (например, без сознания, парализован или ошеломлён). У собственных состояний настройку выбирает игрок. Если свойство было отмечено по ошибке, нажми «Изменить» и сохрани без галочки.

## Концентрация

Поиск показывает доступные пользователю заклинания с признаком «Концентрация»: официальные, публичные и собственные. Уточни название, если нужного заклинания нет среди первых 30 результатов. Для замены текущей концентрации потребуется явная галочка. Одновременно отслеживается одно заклинание. Отметка не расходует ячейку: её использование учитывается в спеллбуке.

Урон, внесённый через калькулятор хитов, создаёт отдельную проверку для каждого источника: спасбросок Телосложения, СЛ = максимум из 10 и половины введённого урона (округление вниз). Введи урон уже после сопротивления и прочих уменьшений. Поглощение временными хитами учитывается в общей сумме урона. Для отдельных источников вноси урон отдельно.

Кнопка «К проверкам концентрации» в калькуляторе закрывает его и открывает нужный блок. Там можно:
- бросить спасбросок на сайте с обычным режимом, преимуществом или помехой;
- отметить успех или провал собственного броска;
- добавить дополнительную проверку со сложностью, назначенной мастером.

Бросок на сайте использует текущий рассчитанный спасбросок Телосложения: модификатор, владение и ручной бонус из настроек персонажа. Успех при результате не ниже сложности. Натуральные 1 и 20 сами по себе не меняют результат обычного спасброска. Ситуативные бонусы, например Благословение, и перебросы учитывай своим броском и кнопками результата.

При успехе удаляется одна ожидающая проверка. При провале прекращается концентрация и удаляются остальные ожидающие проверки. Кнопка прекращения, замена заклинания и состояние с лишением дееспособности также очищают ожидающие проверки.

При достижении 0 хитов концентрация прекращается, в том числе при установке 0 хитов через редактирование. Обычное лечение не отменяет уже назначенные проверки и не восстанавливает прекращённую концентрацию. Короткий отдых её сохраняет. Длинный отдых со сном прекращает; список состояний не очищается ни одним видом отдыха. Длительность самого заклинания отслеживается вручную, а не по реальным часам.

Правила рассчитаны на D&D 5e 2014. Особые классовые исключения, состояние сознания при 0 хитах, особые виды отдыха и автоматическое влияние всех состояний на броски этим обновлением не моделируются.

## Установка через VS Code

Это обновление интерфейса устанавливается поверх предыдущих обновлений концентрации и полей отдыха. Новых миграций нет.

Останови сервер. Положи update_conditions_ui.py рядом с manage.py. Открой файл в VS Code и нажми ▶ «Run Python File» в правом верхнем углу. Установщик сам применит миграцию и проверит проект. После успеха запусти run_server.py кнопкой ▶ и обнови страницу браузера.

Локальные изменения файлов защищены проверкой содержимого. При ошибке установщик восстанавливает файлы и временный снимок SQLite. После успеха временная копия и сам установщик удаляются. Данные персонажей, спеллбуков, состояний справочника и ресурсов отдыха при установке не изменяются.
