# Django Spellbook

Справочники D&D, заклинания, персонажи и книги заклинаний.

## Работа в VS Code

Открой **папку проекта**, в которой находится `manage.py`.
Установи расширение **Python** от Microsoft, если оно ещё не установлено.

1. Нажми `Ctrl+Shift+P` → **Python: Select Interpreter**.
2. Выбери Python из существующей папки `.venv` этого проекта.
3. Закрой старый терминал и открой **Терминал → Создать терминал**.

Теперь обычная команда использует окружение проекта:

```text
python manage.py runserver
```

Открой http://127.0.0.1:8000/. Остановка сервера: `Ctrl+C`.
Если появилась ошибка `No module named django`, повторно выбери `.venv`
и создай новый терминал. Длинный путь к `python.exe` вводить не требуется.

## Запуск без ввода команд

Нажми **Ctrl+Shift+B** — запустится сайт.
Другие операции доступны через **Терминал → Выполнить задачу**:

- **Spellbook: запустить сайт**;
- **Spellbook: проверить проект**;
- **Spellbook: применить миграции**;
- **Spellbook: запустить тесты**.

Задачи используют выбранный в VS Code интерпретатор напрямую, поэтому
не зависят от успешной активации окружения в оболочке терминала.

## Другие команды

В терминале с активированным окружением:

```text
python manage.py check
python manage.py migrate
python manage.py test spells
```

После обновлений схемы базы сначала выполни миграции.
Файлы `spells/migrations/` — часть приложения: их нельзя удалять при чистке.

## Тема оформления

Кнопка «Светлая тема» находится в шапке сайта. Повторное нажатие возвращает
тёмную тему. На узком экране кнопка показана значком солнца; её подпись
доступна при наведении и для экранного диктора. Выбор сохраняется в этом
браузере и применяется при переходах между страницами. По умолчанию тема тёмная.

## Почта и напоминания

Личные параметры SMTP находятся в `email_settings.json` рядом с `manage.py`.
Для новой установки используй `email_settings.example.json` как образец.
В `site_url` укажи адрес сайта, который получатель сможет открыть из письма.
`127.0.0.1` работает только на компьютере, где запущен сайт.

Подтвердить адрес можно в меню **Безопасность → Email и безопасность**.
Напоминания включаются в форме плана; для них нужен подтверждённый адрес.
Дата и время показываются после включения галочки. Часовой пояс — Москва.

Для автоматических писем используется задача Windows **SpellbookEmailReminders**,
которую регистрирует `register_email_reminders.ps1`. После регистрации повторять
настройку при каждом запуске сайта не нужно. Задача проверяет планы каждые
15 минут, пока компьютер включён и пользователь вошёл в Windows.

Проверить причитающиеся письма без отправки:

```text
python manage.py send_plan_reminders --dry-run
```

Отправить причитающиеся письма вручную:

```text
python manage.py send_plan_reminders
```

Журнал фоновой задачи: `logs/email_reminders.log`.
Если SMTP работает без VPN и обрывается с ним, почтовому подключению нужен
рабочий маршрут и при автоматической отправке.

## Импорт заклинаний

Администратору доступен массовый импорт JSON в каталоге заклинаний.
Пример простого формата: `EXAMPLE_SPELLS.json`.
Материальные компоненты хранятся в самом заклинании: название и необязательная
стоимость в золотых монетах. Отдельного справочника компонентов нет.

## Что сохранять

- `db.sqlite3` — текущая база с данными;
- `media/` — загруженные изображения;
- `email_settings.json` — личные параметры отправки почты;
- `secret_key.txt` — постоянный секретный ключ приложения;
- `.venv/` — существующее виртуальное окружение;
- `.git/` — история коммитов;
- `spells/migrations/` — рабочие миграции.

База, изображения, личные настройки, ключ и окружение исключены из Git.
При переносе или резервном копировании сайта их нужно сохранять отдельно.

Старые `apply_*.py`, `*_payload.zip`, `*_manifest.json` и `update_backups/`
не нужны для работы установленного приложения. Они также исключены из Git.
