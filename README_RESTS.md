# Отдых и ресурсы персонажа

Открой персонажа → «Здоровье». Здесь находятся короткий и длинный отдых, кости хитов и счётчики способностей.

## Короткий отдых

После как минимум часа спокойного отдыха можно тратить кости хитов по одной. Текущие хиты и результат лечения видны в том же окне короткого отдыха. Бросок выполняется на сервере: кость + модификатор Телосложения, минимум 0. Хиты не превышают максимум, временные хиты не меняются. При полных хитах кость не тратится.

Кнопка завершения отдельно восстанавливает ячейки колдуна в выбранных спеллбуках и счётчики с восстановлением на коротком отдыхе. Обычные ячейки не восстанавливаются. Выход из окна сохраняет уже потраченные кости.

## Длинный отдых

После как минимум 8 часов отдыха (включая 6 часов сна) восстанавливаются хиты до максимума и обнуляются временные хиты. Если особенность даёт временным хитам другой срок действия, учитывай это отдельно. В начале отдыха нужен хотя бы 1 хит. Отдых восстанавливает до половины общего числа костей хитов, округляя вниз, минимум одну. Для мультикласса можно выбрать типы возвращаемых костей. Предлагаемый выбор сначала возвращает кости большего размера.

В выбранных спеллбуках восстанавливаются обычные ячейки и ячейки колдуна. Максимумы, заклинания и настройки книг сохраняются. Активные книги изначально отмечены; можно снять все галочки. Счётчики короткого и длинного отдыха заполняются до максимума, ручные остаются прежними.

Ограничение одного длинного отдыха за игровые сутки, длительность, прерывания и специальные правила сна проверяет игрок с мастером. Приложение не использует реальные часы вместо игрового времени. Кнопка завершения сразу применяет отдых, без дополнительной галочки. Истощение, смерть и классовые исключения автоматически не рассчитываются.

## Кости хитов и счётчики

Число костей берётся из уровней классов, тип — из класса. Отдельные уровни колдуна дают d8. Если класс не выбран, кость можно указать в редактировании персонажа → «Бой и магия» → «Кость хитов без класса». По умолчанию d8. После установки обновления все кости считаются доступными; для текущей кампании учти это при первом отдыхе.

Добавь ресурс, например «Второе дыхание», укажи максимум и восстановление: короткий и длинный отдых, только длинный или вручную. Кнопки −/+ тратят/возвращают одно использование, не выходя за границы. Новый ресурс начинается полным. Для смены названия или максимума удали счётчик и создай заново с нужными параметрами.

Изменения доступны только владельцу персонажа. Повторная отправка одного действия не применяет отдых дважды. Если данные изменились в другой вкладке, интерфейс обновит их и попросит повторить действие после проверки.

## Установка из VS Code

Останови сервер. Положи update_character_rests.py рядом с manage.py, открой его и нажми ▶ «Run Python File» в правом верхнем углу. Установщик сам применит миграцию и проверит проект. После сообщения об успехе запусти run_server.py обычной кнопкой ▶ и обнови страницу браузера.

Перед изменениями установщик делает временный снимок SQLite и проверяет изменённые файлы. При ошибке возвращает базу и файлы; после успешной установки временный снимок удаляется. Сам файл установщика также удаляется после успеха. Локально изменённые файлы не перезаписываются молча.
